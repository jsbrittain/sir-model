
# Agent Instructions

This repository is used in a course on AI-assisted software engineering.

The aim is to develop a small, understandable research software application while retaining human oversight of design and implementation decisions.

## Project context

- Read `DESIGN.md` before implementing application functionality.
- Treat `DESIGN.md` as the agreed specification.
- Ask for clarification when requirements are ambiguous.
- Do not introduce functionality beyond the agreed scope without approval.

## Implementation

- Prefer simple, readable code over elaborate abstractions.
- Follow established Python conventions.
- Use meaningful names and keep functions focused.
- Prefer the Python standard library.
- Do not introduce dependencies without approval.
- Keep numerical calculations separate from presentation and command-line handling where practical.
- Document scientific assumptions and non-obvious decisions.

## Working practices

Before modifying files:

- Inspect the relevant existing code and project instructions.
- Explain significant design decisions when appropriate.
- Keep changes focused on the requested task.

After modifying files:

- Run the application or relevant checks where possible.
- Report what was changed and what was verified.
- Report any failures or unresolved questions.
- Do not claim that unexecuted checks have passed.

## Boundaries

- Do not modify unrelated files.
- Do not silently change the scientific model or its assumptions.
- Do not create tests unless explicitly requested.
- Do not commit, push or open pull requests without explicit authorisation.
